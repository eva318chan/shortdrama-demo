# 短劇場 · Demo

ReelShort 式直式短劇平台演示版（手機優先單頁網站）。

- https://shortdrama-demo.vercel.app （待部署）
- 源码：https://github.com/eva318chan/shortdrama-demo

## 功能
- **劇場**：直式全屏短劇資訊流，上下滑動切換，點擊暫停/播放，點讚
- **金幣解鎖**：前 3 部免費，其餘每部 10 金幣解鎖（演示流程，每日可領 50 金幣）
- **片庫**：按類型篩選（古裝甜寵 / 武俠動作 / 神話傳說 / 玄幻 / 美食 / 歷史戰爭 / AI武俠 / 親情 / 懷舊 / 西遊）
- **我的**：金幣餘額、已解鎖、觀看歷史（localStorage 本機儲存）
- 10 部示範短劇，影片經壓縮作串流演示

## 說明
演示版：影片為示範內容，不作永久儲存；無正式會員、支付及版權結算系統。
